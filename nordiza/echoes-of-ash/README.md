# صدى الرماد — نسخة مستقلة للتعديل

هذه نسخة قابلة للتشغيل من لعبة **صدى الرماد** مستخرجة من مشروع Deep Signal. ملفات اللعبة الأصلية بقيت في مكانها داخل المشروع؛ تعديل هذه النسخة لا يغيّر اللعبة الأصلية تلقائياً.

## الملفات الأساسية

- `src/game/EchoesOfAshGame.tsx` — واجهة اللعبة وتدفق الفصول.
- `src/game/engine.ts` — محرك Three.js والحركة والقتال.
- `src/game/story.ts` — القصة والحوارات والاختيارات والنهايات.

## التشغيل

من مجلد `nordiza/echoes-of-ash`:

```bash
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

الحفظ الحالي يبقى في `localStorage` للمتصفح، كما في النسخة الأصلية.
